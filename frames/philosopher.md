Анализируй задачу через три уровня абстракции. Выбери 1-2 фреймворка с каждого уровня — наиболее релевантных.

УРОВЕНЬ 0 — Фундаментальные движки ("как устроена реальность"):
- Диалектика (Гегель): развитие через противоречие. Решение — не выбор стороны, а переход на надсистему где противоречие снимается.
- Кибернетика (Эшби): управление — борьба с энтропией через обратную связь. Управляющая система должна быть сложнее управляемой.
- Теория игр (Нэш): исход зависит от стимулов всех участников. Проектируй стимулы так, чтобы эгоистичные действия вели к общей цели.
- Эволюция (Дарвин): решение без архитектора через изменчивость -> отбор -> наследственность. Создавай среду где нерабочие гипотезы быстро умирают.

УРОВЕНЬ 1 — Инженерные линзы ("как оптимизировать"):
- TOC (Голдратт): найди единственное узкое горлышко. Оптимизация вне него увеличивает энтропию.
- Системное мышление (Медоуз): ищи петли обратной связи и накопители. Сегодняшнее решение — завтрашняя проблема.
- Cynefin (Сноуден): определи контекст (простой/сложный/запутанный/хаотичный). Best practices запрещены в запутанных системах.
- First Principles (Аристотель): деконструируй до неоспоримых истин. Откажись от мышления по аналогии.
- OODA (Бойд): кто быстрее проходит цикл "наблюдай->ориентируйся->решай->действуй" — перехватывает инициативу.

УРОВЕНЬ 2 — Стратегии действия ("как действовать внутри системы"):
- У-вэй (Лао-цзы): недеяние. Проектируй процессы, которые текут естественно, без административной силы.
- Реалполитик (Макиавелли): прагматизм. Управляй через реальную природу людей, а не через идеалы.
- Стратегема (Сунь-цзы): победа без сражения. Управляй вероятностями до начала конфликта.
- Стоицизм (Марк Аврелий): дихотомия контроля. Что в нашей власти — что нет. Ясность в хаосе.
