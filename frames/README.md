# Когнитивные фреймы ForgeRace

Фреймы — это линзы мышления для AI-агентов в дискуссиях. Каждый фрейм заставляет модель смотреть на задачу под определённым углом, предотвращая конвергенцию к "средней температуре по палате".

## Принцип

**Модель x Фрейм = Агент-инстанс.** Одна и та же модель (qwen, gemini, claude) с разными фреймами даёт принципиально разные ответы. Три qwen с тремя фреймами — это три специалиста, а не три копии.

## Фреймы

| Фрейм | Файл | Что делает | Когда использовать |
|--------|------|------------|-------------------|
| **octagon** | `octagon.md` | 8 осей выживаемости решения | Проверка архитектурных решений |
| **optimizer** | `optimizer.md` | 4-фазный анализ: grounding → constraints → divergence → red-teaming | Глубокий разбор сложной задачи |
| **vectors** | `vectors.md` | 10 когнитивных векторов (дедукция, инверсия, латераль...) | Поиск нестандартных решений |
| **conflicts** | `conflicts.md` | Арбитраж конфликтов между осями, trade-off матрицы | Выбор между альтернативами |
| **philosopher** | `philosopher.md` | 13 мета-фреймворков (диалектика, теория игр, стоицизм...) | Концептуальный анализ, стратегия |
| **lateral** | `lateral.md` | Дикие стратегии, инверсия, детектор консенсуса | Когда все согласны (опасный знак) |

## Использование в дискуссиях

```bash
# В интерактивном чате:
/qwen+octagon           # qwen анализирует через 8 осей
/gemini+lateral         # gemini ломает шаблоны
/qwen+conflicts         # qwen арбитрирует trade-offs

# В пакетном режиме:
./fr discuss reply my-topic --agent qwen+optimizer
```

## Комбинации для бесплатного Qwen

Три qwen-специалиста за $0:

```
/qwen+octagon     — "выживет ли это решение?" (структурный аналитик)
/qwen+lateral     — "а что если всё наоборот?" (провокатор)
/qwen+conflicts   — "какую цену мы платим?" (арбитр)
```

## Происхождение

Фреймы адаптированы из Knowledge Base проекта [abracadabra](../abc/) — системы когнитивного анализа для AI-агентов. Оригинальные инструменты (Инженерный Октагон, Универсальный Оптимизатор, Матрица Конфликтов, Векторы Мышления, Когнитивный Ландшафт) сжаты до размера, при котором маленькие модели не теряют контекст (Lost in the Middle).

## Создание своих фреймов

```toml
# Inline в forgerace.toml:
[frames.myframe]
description = "Краткое описание для /help"
content = """Инструкция для агента..."""

# Или из файла:
[frames.myframe]
description = "Краткое описание для /help"
file = "frames/myframe.md"
```

Правила хорошего фрейма:
- До 2KB текста (маленькие модели тонут в больших промптах)
- Начинай с действия ("Анализируй...", "Перед ответом..."), не с описания
- Давай конкретную структуру вывода (оси, фазы, матрицы)
- Заканчивай чётким критерием: что агент должен назвать/показать
