# Когнитивные фреймы ForgeRace

Фреймы — линзы мышления для AI-агентов в дискуссиях. Модель x Фрейм = агент-инстанс.

## Фреймы

| Фрейм | Вопрос | Когда использовать |
|--------|--------|-------------------|
| **+audit** | выживет ли? | Проверка архитектурных решений по 8 осям |
| **+wild** | а если наоборот? | Слом шаблонов, когда все согласны (опасный знак) |
| **+price** | какой ценой? | Выбор между альтернативами, trade-off матрицы |
| **+theory** | какой принцип? | Анализ от теории к реализации |
| **+evidence** | какие факты? | Анализ от конкретики к обобщению |
| **+optimizer** | разбери по фазам | Глубокий 4-фазный разбор с red-teaming |
| **+meta** | какой закон? | Концептуальный анализ через 13 мета-фреймворков |
| **+vectors** | какой инструмент? | 10 когнитивных векторов (дедукция, инверсия, парадокс) |

## Сценарии

```
Проверь → сломай → оцени    /agent+audit → /agent+wild → /agent+price
Глубокий разбор              /agent+optimizer → /agent+meta → /agent+audit
Дебаты                       /agent+theory → /agent+evidence → /agent+price
```

## Использование

```bash
# В чате:
/qwen+audit                    # qwen проверяет по 8 осям
/qwen+wild                     # qwen ломает шаблоны
/all qwen+audit,qwen+wild      # два qwen подряд

# Пакетно:
./fr discuss reply my-topic --agent qwen+optimizer
```

## Создание своих фреймов

```toml
[frames.myframe]
description = "краткое описание для /help"
content = """инструкция для агента..."""
# или из файла:
# file = "frames/myframe.md"
```

До 2KB текста. Начинай с действия. Давай структуру вывода. Заканчивай критерием.
